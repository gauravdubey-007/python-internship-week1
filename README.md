# Python Internship Assignments (Week 1)

Beginner Python programs covering loops, conditionals, functions and modular programming.

## Programs

| File | Description |
|------|-------------|
| `temperature_converter.py` | Convert Celsius to Fahrenheit and back using functions |
| `grade_calculator.py` | Take marks for each subject, calculate total and average, assign a grade |
| `number_checker.py` | Check whether a number is even/odd and whether it is prime |
| `atm_simulator.py` | **Mini Project:** PIN-based ATM with balance check, deposit and withdraw |

## How to Run

Requires Python 3.8 or higher.

```bash
python temperature_converter.py
python grade_calculator.py
python number_checker.py
python atm_simulator.py
```

## ATM Simulator Details

- Default PIN: `1234` (3 attempts allowed)
- Starting balance: Rs. 1000
- Options: Check Balance, Deposit, Withdraw, Exit
- Each operation is a separate function (`login`, `check_balance`, `deposit`, `withdraw`)
- Handles invalid input and insufficient balance

## Skills Practiced

Loops, conditionals, functions, input validation, modular programming.
